# 대전꽃백화점 홈페이지 + 관리자페이지 프로토타입

## 고객 화면
- `/`

## 관리자 화면
- `/admin`
- 아이폰에서 `https://내-vercel-주소.vercel.app/admin` 으로 접속하면 됩니다.
- 현재는 UI/UX 확인용으로 관리자 로그인 없이 바로 열립니다.
- 주문/상품/상담 데이터는 샘플 데이터이며 새로고침하면 초기화됩니다.

## 실행
```bash
npm install
npm run dev
```

로컬 관리자 화면: `http://localhost:3000/admin`

## Vercel
이번 ZIP은 압축을 풀었을 때 `package.json`, `app`, `public`이 최상단에 바로 보이도록 구성합니다.
GitHub 새 저장소 최상단에 이 파일들을 올리면 Vercel Root Directory는 `./` 그대로 두면 됩니다.
